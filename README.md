## Описание проекта

Система предназначена для:
- Проведения тестирования студентов
- Автоматического оформления акта ЛУ-23
- Управления группами студентов
- Назначения задач группам
- Ведения статистики успеваемости

## Технологии

Backend:
- Laravel 11.x
- PHP 8.2+
- SQLite
- Sanctum

Frontend:
- React 18.x
- TypeScript 5.x
- Vite 5.x
- Fetch API

## Функциональные возможности

Для учителя:
- Управление группами (создание, редактирование, удаление)
- Управление задачами (создание, редактирование, удаление, скрытие/показ)
- Назначение задач группам
- Просмотр результатов тестов
- Комментарии к результатам
- Просмотр актов ЛУ-23
- Список учеников
- Статистика успеваемости

Для ученика:
- Регистрация с выбором группы
- Вход по email/паролю
- Просмотр задач (только назначенных группе)
- Изучение материалов
- Тестирование (Верно/Неверно)
- Просмотр своих результатов
- Отображение комментариев учителя
- Заполнение акта ЛУ-23
- Просмотр документа
- Профиль со статистикой

## Установка и запуск

Требования:
- PHP >= 8.2
- Composer
- Node.js >= 18
- SQLite

Установка:

```bash
git clone <репозиторий>
cd diplom
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan storage:link
php artisan serve
npm run dev
